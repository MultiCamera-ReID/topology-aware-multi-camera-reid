# Topology-Aware Multi-Camera Person Re-Identification

A final-year project focused on developing a **multi-camera person re-identification (Re-ID) system** for campus environments.

The system aims to identify the same person across different CCTV cameras by combining **person appearance, temporal information, motion, observation quality, and camera topology**.

A key focus of the project is to **learn relationships between cameras** and use this topology to improve cross-camera person association and make person searches more efficient.

## Project Objectives

* Detect and track people across multiple cameras.
* Re-identify the same person across different camera views.
* Learn and maintain camera-to-camera relationships.
* Use spatial and temporal information to improve association.
* Search for a person based on available observations.
* Visualize the observed movement and trajectory of a person across the camera network.
